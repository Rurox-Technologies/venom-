# UI Direction

## Reference Goals

The UI should feel like a futuristic AI operating system dashboard with low-noise information density and high contrast readability.

## Visual Language

- Deep dark background with subtle grid texture
- Glassmorphism panels with soft border glow
- Cyan/blue neon accents for active states
- Compact status labels and signal indicators
- Rounded but sharp-feeling control surfaces

## Interaction Style

- Framer Motion powered enter/reveal transitions
- Calm, meaningful micro-animations (not noisy)
- Voice button with pulse and listening/speaking states
- Streaming/typing indicators in chat thread

## Layout Guidance

- Top utility navbar (docs/changelog/status style)
- Left sidebar for history, modes, and settings
- Primary center chat workspace
- Floating controls for voice and quick actions

## Responsiveness

- Desktop: split sidebar + main workspace
- Tablet/mobile: collapsible sidebar and sticky input actions
