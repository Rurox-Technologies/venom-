# Contributing to Venom

Thank you for your interest in contributing to Venom! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/venom.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Run tests: `cd backend && pytest`
6. Commit and push your changes
7. Open a Pull Request

## Development Guidelines

- Follow existing code style and conventions
- Write tests for new features
- Update documentation as needed
- Keep commits focused and descriptive

## Code of Conduct

Be respectful, inclusive, and constructive in all interactions. Harassment or toxic behavior will not be tolerated.

## Need Help?

Open an issue or reach out to the maintainers.
